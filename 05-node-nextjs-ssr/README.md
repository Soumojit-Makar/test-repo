# Next.js SSR Demo

## Deploy Settings
| Field | Value |
|-------|-------|
| **Project Name** | `nextjs-ssr` |
| **Build Command** | `npm install && npm run build` |
| **Start Command** | `npm start` |
| **Port** | `3000` |
| **Service Type** | `DYNAMIC` |
| **Mode** | Serverful **or** Serverless |

## What it demonstrates
- `getServerSideProps` — fetches data server-side on every request
- Shows the **server render timestamp** (refreshes on every page load)
- Also includes an API route at `/api/hello`
