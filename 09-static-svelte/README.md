# Svelte + Vite Static Demo

## Deploy Settings
| Field | Value |
|-------|-------|
| **Project Name** | `svelte-static` |
| **Build Command** | `npm install && npm run build` |
| **Start Command** | *(leave blank — static site)* |
| **Port** | *(leave blank)* |
| **Service Type** | `STATIC` |

## Features
- Svelte reactive variables (no virtual DOM)
- Interactive click counter
- Functional todo list with add + toggle
- Glassmorphism dark UI with Svelte's scoped styles
